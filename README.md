# 与你油约

面向在校学生的响应式校园找搭子与互助平台。项目以“发布需求 → 搜索筛选 → 申请 → 审核 → 组队 → 评价”为核心，同时覆盖代购、二手、跑腿、租借、换课、校园问答和后台治理。

## 技术栈

- Next.js 16 App Router + React 19 + TypeScript
- Node.js 24 内置 `node:sqlite`，无需单独安装数据库
- React Server Components、Server Actions 与 Route Handlers
- 原生 CSS 设计系统 + Lucide 图标
- Vitest 单元测试、ESLint、TypeScript 严格检查

选择这一组合的原因是：项目既需要公开检索页面，也需要登录后的申请、审核和管理流程；全栈 React 可以在单个工程中完成页面、接口与服务端数据访问，SQLite 则适合课程项目、单机演示和快速部署。

## 已实现功能

- 用户注册、登录、HttpOnly 会话、个人资料
- 搭子需求发布、分类/关键词筛选、详情与公开留言
- 申请加入、收到/发出申请、同意/拒绝、申请清理
- 组队成功通知、联系方式开放、我的搭子、完成与评价
- 搭子计划收藏夹、热门排序与基于兴趣/专业/校区的匹配推荐
- 独立通知中心、未读角标、单条跳转、全部已读与已读清理
- 我的搭子计划管理、招募关闭与重新开放
- 已发布计划编辑、申请主动撤回与再次申请
- 组队后的私密搭子空间、站内消息与未读提醒
- 公开个人主页、同行数据、评价概览与隐私保护提示
- 代购、二手、跑腿、租借、换课、问答的统一发布与检索
- 互助响应、发布者确认、接单人、进度/完成/取消状态管理
- 本地数据检索“小油助手”，不向第三方发送用户问题
- 用户停用、内容审核、举报处理后台
- 完整演示种子数据、空状态、错误页和响应式布局

## 本地运行

要求 Node.js 24+ 与 pnpm 11+。

```bash
pnpm install
pnpm db:seed
pnpm dev
```

浏览器打开 `http://localhost:3000`。

演示账号：

- 学生：`13800000001` / `student123`
- 管理员：`13900000000` / `admin123456`

重置演示数据：

```bash
pnpm db:reset
```

## 质量检查

```bash
pnpm check
```

该命令依次执行 ESLint、TypeScript 类型检查、Vitest 测试和生产构建。

## 数据与部署

默认数据库为 `data/meet-with-you.db`，首次启动会自动建表。可通过 `DATABASE_PATH` 改变路径。生产环境建议使用持久化磁盘并通过 Node.js Server 或 Docker 部署；若扩展为多实例服务，应将 SQLite 替换为 PostgreSQL，并增加对象存储、短信验证、内容风控和审计日志。

## 安全说明

密码使用 Node.js `scrypt` 加盐哈希；登录态使用数据库中的随机会话令牌和 HttpOnly Cookie。项目不包含支付担保、实名认证或真实 AI 大模型调用，公开部署前仍需补充 CSRF 防护、登录限流、验证码、文件上传安全和隐私合规流程。
